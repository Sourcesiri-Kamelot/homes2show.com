## 🛠️ **TECHNICAL ARCHITECTURE:**

### **🗄️ AWS S3 STORAGE:**
- **Bucket**: `homes2show-images-prod`
- **Structure**: Organized by type and entity
- **Access**: Public read for display, secure upload
- **CDN**: Global delivery via CloudFront

### **📁 FOLDER STRUCTURE:**
```
homes2show-images-prod/
├── agents/
│   └── {agent-id}/
│       └── profile-{timestamp}.jpg
├── properties/
│   └── {brokerage-id}/
│       └── {property-id}/
│           ├── image-1-{timestamp}.jpg
│           ├── image-2-{timestamp}.jpg
│           └── ...
└── brokerages/
    └── {brokerage-id}/
        ├── logo-{timestamp}.jpg
        └── display-{timestamp}.jpg
```

### **🔧 IMAGE PROCESSING:**
- **Agent Profiles**: 400x400px, 90% quality
- **Property Images**: 1200x800px, 80% quality  
- **Brokerage Logos**: 300x300px, 90% quality
- **File Types**: JPEG, PNG, WebP
- **Max Size**: 10MB per image
- **Compression**: Automatic optimization
